Evaluate the experience as a traveler or trip organizer, not a programmer.
Can a new member understand where to go, propose changes, review others' ideas, and
know which itinerary is shared versus draft? Inspect navigation, wording, hierarchy,
keyboard access, small screens, confusing states, and accidental destructive paths.
Read `impeccable` for UI review. Use actual observations of the running app, not
assumed behavior. Return a few concrete friction points with reproduction and
severity.
