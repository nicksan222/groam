# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Everybody: humans and AI agents collaborating to plan trips. Open-source participation is central to the product.

## Product Purpose

An open-source shared place where people and agents turn trip ideas into agreed plans.

## Capabilities and Constraints

The existing application provides shared itineraries, reviewable proposals, issues, conversations, and contextual AI assistance. The web app uses the shared UI package. Preserve working product behavior during design changes.

## Brand Commitments

The product uses a refined shadcn-style, all-sans design system: white and soft neutral light surfaces, evergreen light-mode actions, a near-black achromatic dark hierarchy with evergreen actions, quiet hairlines and compact rounded controls. The Groam brand mark reserved for applicable brand and authentication surfaces. Humans and AI agents collaborate in the same understandable trip workspace; the private assistant docks at wide desktop sizes and overlays smaller screens.

## Evidence on Hand

README.md describes current capabilities. The repository contains seeded demonstration trips and existing brand assets. Concept mockups are illustrative, not implemented screens.

## Product Principles

- Make human and agent collaboration understandable.
- Keep proposed changes distinguishable from agreed plans.
- Make shared trip planning approachable.
