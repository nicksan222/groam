# Maintainers

Maintainers are responsible for the project's technical direction, releases,
community standards, and repository administration.

## Current maintainers

| GitHub                                       | Role               |
| -------------------------------------------- | ------------------ |
| [@nicksan222](https://github.com/nicksan222) | Project maintainer |

The repository's review ownership is defined in
[`.github/CODEOWNERS`](.github/CODEOWNERS). Code ownership identifies requested
reviewers; it does not prevent contributions from anyone.

## Responsibilities

Maintainers are expected to:

- review and merge contributions based on technical merit and project fit;
- triage issues and keep public project documentation accurate;
- manage releases and respond to private vulnerability reports;
- apply the [Code of Conduct](CODE_OF_CONDUCT.md) consistently; and
- disclose conflicts of interest that could affect a project decision.

As the contributor community grows, maintainership may be offered to sustained,
trusted contributors who demonstrate sound judgment, constructive collaboration,
and care for the project. Any change to the maintainer list is made through a
pull request so the decision remains visible in repository history.
