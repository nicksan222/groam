# Support

Groam is maintained as an open-source project. Support is provided on a
best-effort basis through this repository.

## Before asking for help

1. Read the local setup instructions in [CONTRIBUTING.md](CONTRIBUTING.md).
2. Search the [documentation](README.md) and
   [existing issues](https://github.com/nicksan222/groam/issues).
3. Reduce the problem to the smallest reproducible example and remove secrets,
   tokens, and personal data from logs or screenshots.

## Where to ask

- Use the [question form](https://github.com/nicksan222/groam/issues/new?template=question.yml)
  for setup, usage, and contribution questions.
- Use the [bug report form](https://github.com/nicksan222/groam/issues/new?template=bug-report.yml)
  for reproducible incorrect behavior.
- Use the [feature request form](https://github.com/nicksan222/groam/issues/new?template=feature-request.yml)
  for product ideas and improvements.

Maintainers may convert a support question into a bug or feature request, close
duplicates, or ask for more information. Response times are not guaranteed.

## Security

Do not report vulnerabilities in a public issue. Follow the private reporting
process in [SECURITY.md](SECURITY.md).
