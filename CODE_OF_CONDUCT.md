# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in Groam a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal
appearance, race, caste, color, religion, or sexual identity and orientation.

## Enforcement

Report unacceptable behavior through GitHub Security Advisories or by opening
a private maintainer contact if one is listed on the repository. Maintainers
will review and respond as appropriate.
